## Overview

The HW Hanna Warner & Associates CPAs website is a contemporary and responsive online presence designed to showcase the accounting firm's services and expertise. Developed using modern web technologies, it aims to provide a user-friendly and informative experience for potential and existing clients.

## Features

This website incorporates several key features to enhance user engagement and provide essential information effectively:

* **Modern, Responsive Design:** Ensures optimal viewing and interaction across all devices, including desktops, tablets, and smartphones.
* **Smooth Scroll Navigation:** Facilitates easy and intuitive navigation through different sections of the website.
* **Interactive UI Elements with Hover Effects:** Adds visual interest and provides feedback to user interactions.
* **Mobile-Friendly Layout:** Guarantees a seamless and accessible experience for users accessing the site on mobile devices.
* **Optimized Performance:** Built with Next.js for fast loading times and efficient performance.
* **SEO-Friendly Structure:** Implemented with search engine optimization best practices to improve online visibility.

## 🛠️ Tech Stack

The website is built using a modern and efficient technology stack:

* **Next.js 14:** A React framework that enables server-side rendering and the creation of fast, SEO-friendly web applications.
* **Tailwind CSS:** A utility-first CSS framework for rapid and customizable styling.
* **Lucide Icons:** A collection of clean and consistent icons used throughout the website.
* **Vercel:** The recommended platform for deploying and hosting Next.js applications, offering optimized performance and scalability.

## Deployment

The website is deployed on **Vercel**, a platform specifically designed for hosting modern web applications like those built with Next.js, ensuring optimal speed and reliability.
